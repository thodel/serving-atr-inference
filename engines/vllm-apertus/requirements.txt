# ships forks, pinned below to the commits their model card and their release
# image (github.com/swiss-ai/model-launch, images/vllm_apertus_1.5_release) name.

# same wall as the default vLLM wheels (#132). So the fork is installed the way
# the image installs it, VLLM_USE_PRECOMPILED=1, but with the kernels taken from
# the *cu129* nightly of the upstream commit the fork is based on, and torch from
# the cu129 index. scripts/make_venvs.sh vllm-apertus does all of that; this file
# carries only what pip can install unaided, before the fork.
#
# Build requirements of the fork (requirements/build/cuda.txt at a601a9d), needed
# because it is installed with --no-build-isolation against the torch above.
